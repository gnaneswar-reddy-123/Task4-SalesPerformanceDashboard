# Sales Performance Dashboard

## Objective
Designed an interactive Power BI dashboard to analyze sales performance using the Superstore dataset.

## Tools Used
- Microsoft Power BI
- Superstore Dataset
- Data Visualization

## Dashboard Features
- KPI Cards
- Sales Trend Analysis
- Category-wise Sales
- Regional Sales
- Segment-wise Sales
- Interactive Slicers

## Key Insights
- Total Sales: 2.26M
- Total Orders: 9.8K
- Total Customers: 793
- Technology generated the highest sales.
- West region recorded the highest sales.
- Consumer segment contributed the most sales.
